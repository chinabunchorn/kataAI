# Abandoned custom scratch patch evidence

Archived unchanged from `infra/kata-scratch/` on 2026-11-15 before removing that
directory and its custom Rust patch. These are original check/test logs and
`verification.json`, retained as historical evidence, not passing runtime
acceptance. Original paths and the patch hash in the record describe the removed
work; the patch itself, installation/correction proposals and obsolete review
were deleted. No custom runtime artifact was installed by this cleanup.

KataAI now uses the existing unmodified Kata runtime. Exact 16 MiB guest scratch
enforcement is no longer a release requirement. See the
[current acceptance policy](../../../../../../docs/infrastructure/M3_ACCEPTANCE.md).
